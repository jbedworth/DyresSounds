## Summary

The sounds and sound picker that Dyre's AddOns share, for World of Warcraft: Forever

## Description

**Dyre's Sounds** holds the sounds and the sound menu that Dyre's AddOns share. It is a library: it does nothing on its own. Install it when one of Dyre's AddOns asks for it; the CurseForge app installs it for you.

### What it has
- **Dyre's Picks:** nine effect sounds that ship with it, first in every sound menu.
- The game's interface sounds, the Cooldown Manager's alert sounds, imp sounds, and Text to Speech.
- A sound menu grouped like the Cooldown Manager's; choosing a sound plays it.

### Compatibility
Beta, for the Forever beta client 1.60.1. WowUp users (2.24.0 or later): install from the repository URL; GitHub releases carry the Forever metadata WowUp needs.
